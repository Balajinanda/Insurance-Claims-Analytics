# Insurance-Claims-Analytics


## Project Overview

The Insurance Claims Analytics Project is an end-to-end data analytics project designed to analyze customer insurance claim data and identify key business insights related to claims, demographics, health conditions, and customer risk factors. This project demonstrates practical skills in SQL, Python, and Power BI commonly used in Data Analyst roles.

## Tools Used

### SQL Server
- Data validation
- Data exploration
- Business analysis
- Aggregations and filtering

### Python 
- Data cleaning
- Exploratory Data Analysis
- Data visualization

### Power BI
- Dashboard creation
- KPI reporting
- Interactive visualizations

## SQL Analysis Performed
Imported and validated insurance customer data in SQL Server.
Performed data quality checks and record validation.
Analyzed customer demographics including age, gender, and region.
Evaluated claim trends across different customer segments.
Compared claim amounts between smokers and non-smokers.
Analyzed claim behavior of diabetic and non-diabetic customers.
Identified high-risk customer groups using age, BMI, and health indicators.
Calculated total claims, average claims, and customer distributions.
Generated business insights to support risk assessment and decision-making.
### Key Insights
Smoking status significantly impacts insurance claim amounts.
Diabetic customers tend to generate higher claims.
Regional differences exist in claim expenditure.
Customer age and BMI are important indicators of insurance risk.
